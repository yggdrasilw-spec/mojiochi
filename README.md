# もじおち（kana-drop）

落ちてくるひらがなブロック（1モーラ）を並べて、辞書の単語を作って消す落ちものパズル。設計の経緯と判断は `DESIGN.md`。

## ファイル

- `kana_drop.html` — 納品物（単一HTML、辞書同梱）。**直接編集しない**
- `kana_drop_template.html` — 本体テンプレート。編集はここに行う
- `dict.json` — ゲーム用辞書（111,070語： 読み・表記・意味）
- `build.py` — テンプレートに dict.json を注入して kana_drop.html を生成
- `build_dict.py` — しりとり辞書（hiragana-ninshiki の配信データ）から dict.json を抽出（要ネット）
- `dict_src/` — 辞書抽出の作業データ（再生成可能）
- `tests/test_harness.js` — 判定ロジックとプレイシミュレーションの検証

## ビルドと検証

```bash
python3 build.py
# 検証： kana_drop.html の script を tests/test_harness.js のマーカーに差し込んで node 実行
```

## 辞書データの出典

しりとりアプリ（yggdrasilw-spec/hiragana-ninshiki）の配信辞書【全件】から、読みがひらがなのみ・2〜7モーラの語を抽出（全レベル・全カテゴリ、固有名詞含む）。語の意味は同辞書の編集データ（原典は JMDict／日本語WordNet 由来のエントリを含む）。

## 遊び方

- 画面のどこをなぞっても、指（マウス）の移動量だけ落ちるブロックが左右に動く相対ドラッグ（ブロックが指で隠れない）。下フリックか「おとす」ボタンで即落下。キーボード ←→↓＋スペースにも対応
- 横・縦・斜め（左上→右下）の一列に辞書の単語が並ぶと消える（最長一致優先。縦・斜めは上から下へ読む。方向同士でセルを共有する場合は片方だけ）。消えたら落下して連鎖
- 消去演出：セルごとの粒子、単語ごとのスコアポップ（縦単語は「たて！」）、ヒットストップ、5文字以上で盤面が光る、連鎖トーストは跳ねて表示。出現アシストとヒント表示も縦対応
- 接地後 0.42 秒は横に滑らせることができる（ロックディレイ）
- 出現は完全な一様ランダム（頻出モーラへの寄せ・出現アシストなし。意図せず単語ができすぎたため廃止）。ヒント表示（あと1モーラで単語になる並びが破線で光る）は残している
- モード：エンドレス／お題ミッション（3つのお題を達成）／ことばずかん（localStorage に記録）

## もじつみモード（第2モード）

- 曲線の器（角丸フィールド）に円形ブロックがぱらぱら落ちてきて積もる、物理ベースの90秒スコアアタック
- 低重力＋高弾性でブロックが弾む。近くのブロック同士が「つながって」おり、なぞって単語を作る（判定は近接式で、隙間があっても・ななめでも繋がる。速くなぞっても補間判定で途切れない）
- 消えるのはなぞった単語だけ（自動連鎖なし）。消えた分は上からぱらぱら補充される
- 先行入力：ブロックの静止を待たずに次の単語をなぞって示せる（黄色の破線で予約表示）。予約した単語は前の消去が終わり次第どんどん連続で消える
- 掴みは「押した円の中のブロック」を優先し、少し遠くのブロックとも繋がる。小さい「っ」は単独では出現せず、「つ」で代用して単語を作れる（記録・読み上げは本来の読みで）
- 長い単語ほどボーナスが厚い（4文字+30 / 5文字+120 / 6文字+270 / 7文字+480）。消去時はヒットストップ（物理とタイマーが一瞬止まる）＋繋がったまま光ってその場で膨らんで一緒に消える演出、5文字以上で盤面が光る。なぞり中のブロックは固定され、指の下でズレない
- 作った単語は落ちものモードと共通の「ことばずかん」に貯まる
- 救済機能「ゆらす」（3回まで）：全ブロックを物理で跳ねさせて並びを変える
